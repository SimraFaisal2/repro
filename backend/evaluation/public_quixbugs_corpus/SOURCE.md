# QuixBugs slice

Source: https://github.com/jkoppel/QuixBugs at `4257f44b0ff1181dedaedee6a447e133219fcebf`.

QuixBugs is a function-level benchmark. Each converted case contains the buggy program and the public JSON testcases as a pytest suite. These are reported separately from the repository-level held-out corpus.
